# Glossary (`hoggar-bound-lab`)

Quick domain and verification reference (see also the extended mathematical [GLOSSARY.md](../GLOSSARY.md) at the repository root).

- **Context (Pauli line):** A triple $\{u, v, u+v\}$ of distinct, mutually commuting non-identity $N$-qubit Pauli observables whose product is $\pm I$. Each context contributes 6 ordered commuting pairs (`flags`).
- **Contextuality degree $d(S)$:** The minimum number of contexts in $S$ that every noncontextual $\pm 1$ value assignment $f: S \to \{\pm 1\}$ must violate.
- **Spectral floor (Theorem 1):** The universal upper bound $(D-1)\beta_6(S,f) \le (D-2)|S|\sqrt{(D-1)|S|}$ on satisfied-minus-violated flags, derived via Okumura's third-moment inequality.
- **Kramers / quaternionic floor (Theorem 2):** Tighter spectral floor when an antiunitary operator $\theta = P_w K$ with $\theta^2 = -I$ commutes with $A_f$, forcing even eigenvalue multiplicities and halving the effective dimension to $D/2$.
- **Flat pure state:** A unit state $|\psi\rangle \in \mathbb{C}^{2^N}$ whose Pauli expectation values $|\langle \psi | P_u | \psi \rangle|$ take one constant nonzero value on $S$ and vanish on all non-identity Paulis outside $S$.
- **Non-closed configuration:** A set $S$ containing two distinct commuting observables $u, v \in S$ whose product $u + v$ lies outside $S$ (ruling out quadrics and classical subspaces).
- **Sign carrier & completion matrix:** For a closed configuration $X$ and hyperplane $H = X \cap d^\perp$, a sign carrier is $A_\sigma = \sum_{s \in H} \sigma(s) P_s$ and its completion matrix $\Lambda_\sigma$ is the signed adjacency operator on the outside set $O = X \setminus H$.
- **Cospectral carriers / Jonah's Conjecture E:** Two sign carriers $\sigma, \tau$ on $H$ with identical characteristic polynomials (equivalently identical Hermitian eigenvalue multisets) whose completion matrices $\Lambda_\sigma, \Lambda_\tau$ have unequal spectra.
- **MET-SDP dual certificate:** An exact integer semidefinite + metric (frustrated-triangle) cutting-plane dual proof proving global binary QUBO optimality without floating-point arithmetic.
- **`lake comparator --paranoid`:** Lean 4.35.0's built-in sandboxed verifier matching an isolated `Challenge` specification against a sorry-free `Solution` and replaying exports across 6 independent kernels (`Lean 4 C++`, `leanchecker-paranoid`, `lean4lean`, `nanoda`, `con-leche`, `con-ron`).
- **SWHID:** Software Hash Identifier (ISO/IEC 18670:2025), an intrinsic cryptographic content identifier archived by Software Heritage.
- **SLSA Attestation:** Sigstore-signed build provenance generated by GitHub Actions (`actions/attest-build-provenance`) binding a release artifact's SHA-256 to its exact workflow and commit SHA.
