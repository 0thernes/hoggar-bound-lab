A finite research result

This four-qubit pair was the first instance of the strict-law failure predicted by Jonah’s Conjecture E. The combined paper extends it to every number of qubits, with a Lean proof for case C3, and to all nine vertex cases, which proves the conjecture; outside case C3 that proof is on paper, self-contained since v1.4.0, and checked by exact computation.

The preprint is not peer reviewed. The work makes no claim of absolute historical priority, a new contextuality degree, or a physical quantum-hardware experiment.

Built on attributed prior work

B. W. Jonah posed the C3 sign-carrier question and developed the completion-spectrum framework. His v0.5 preprint left C3 open for four or more qubits. This certificate supplies the explicit four-qubit instance predicted by that conjecture.

The earlier spectral floor is attributed to Jonah; this repository’s corresponding contribution is formalization and reproduction. See the papers for the full bibliography and the bounded prior-art search.

Evidence you can inspect

The browser demo recomputes exact integer certificates when signs change. Independent programs reconstruct Pauli matrices and signed contexts, and deliberate mutations test whether checks detect a broken certificate.

Reproduction records include the context verifier, serial Eshkol run, and hosted artifact hashes. The stack uses classical software simulation and a classical quantum-inspired generator; no quantum-hardware advantage is claimed.
