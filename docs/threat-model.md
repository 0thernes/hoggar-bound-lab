# Threat Model (`hoggar-bound-lab`)

This threat model catalogs the **epistemic, formal-verification, computational, and supply-chain attack vectors** that could invalidate a claim in `hoggar-bound-lab` or compromise a verifier's machine (Build Standard B36 & Playbook Layer 1–6).

| Threat / Attack Vector | Impact | Mechanical Control in `hoggar-bound-lab` | Residual Risk |
| --- | --- | --- | --- |
| **1. Vacuous or silently weakened Lean definition** | Theorem compiles but proves a trivial or unintended statement. | Isolated `lean/HoggarBound/Challenge.lean` checked against `Solution.lean` via `lake comparator --paranoid`; 10 explicit existential witness theorems in `lean/HoggarBound/NonVacuity.lean`; line-by-line [docs/statement-fidelity.md](statement-fidelity.md). | Requires human mathematician review to confirm informal English matches Lean definitions. |
| **2. Single-kernel soundness bug or metaprogramming exploit** (e.g. Lean `#14576`, July 2026) | Forged proof accepted by one kernel or environment injection. | Sandboxed (`bwrap`) `lake comparator --config comparator.json --paranoid` on Ubuntu 24.04 CI replaying proof exports across **6 independent kernels** (Lean 4.35.0 C++, `leanchecker-paranoid`, `lean4lean`, `nanoda` 0.4.19, `con-leche`, `con-ron`). | Shared bugs across all 6 kernels at the same release remain theoretically possible. |
| **3. Hidden axiom, `sorry`, or compiler trust (`native_decide`)** | Unsound shortcut bypasses kernel checking. | `VerifyNewFormalizations.lean` audits all 110 declarations strictly within `[propext, Classical.choice, Quot.sound]`; CI enforces zero `sorry`/`admit`/`native_decide`/`unsafe`/custom `axiom` across all proof modules; `lake comparator` rejects non-permitted axioms. | `Challenge.lean` contains intentional `sorry` stubs (explicitly isolated as target spec, never imported by `Solution.lean` or `VerifyNewFormalizations.lean`). |
| **4. Floating-point illusion in numerical verifiers** | IEEE-754 rounding hides violations near sharp thresholds. | Every headline computational bound (`c3_exact_optima_check.py`, `c3_sdp_dual_check.py`, `conjecture_e_trace_formula.py`, `norm_phase_family.py`, `exact_degrees_n4_n5.py`) uses exact integer/SymPy arithmetic; `scripts/arithmetic_audit.py` classifies every script's arithmetic tier. | Exploratory discovery scripts (`flat_states.py`, `phase_states.py`) use float64 and are explicitly tagged `numerical_approximation`. |
| **5. Memory corruption / UB in C11 census programs (`src/*.c`)** | Wrong orbit/rank counts from out-of-bounds access or signed overflow. | Compiled with `-std=c11 -Wall -Wextra` and executed under `-fsanitize=address,undefined` in CI; `w52_census_verify.c` output is cross-checked by pure-integer Python (`exact_degrees_n4_n5.py`) and matches Jonah `[J1]`. | Exhaustive 540.3M-form $N=9$ run takes minutes so CI runs sanitizers on bounded smoke inputs + full `hoggar.c`. |
| **6. Hallucinated or broken scholarly citations / literature rediscovery** | False novelty claim or fabricated reference. | `scripts/check_citations.py` checks DOI/arXiv/Zenodo/URL identifiers in the paper; `results/literature-audit.md` and `results/frontier-prior-art.md` document bounded searches; non-peer-reviewed preprints are explicitly labeled. | Bounded literature search cannot guarantee absolute historical priority. |
| **7. Mutable repository, forged logs, or supply-chain tampering** | Post-hoc edits or tampered release binaries. | All GitHub Actions pinned by full commit SHA; `release.yml` emits `SHA256SUMS` + Sigstore SLSA attestations (`actions/attest-build-provenance`); Software Heritage SWHIDs + `0thernes-research-archive` submodule pins; `gitleaks` & `osv-scanner` in CI. | Git commits/tags are currently unsigned (tracked in `LIMITATIONS.md` as optional owner SSH signing step). |
